# SecureFork Electron Client (React)

UI moderna con Electron + React. Esta version es un prototipo visual con pestañas y formulario de conexion. La integracion real con la app Java se puede hacer mediante API local, WebSocket o gRPC.

## Requisitos
- Node.js 18+ (recomendado)
- npm

## Ejecutar en modo desarrollo
```bash
npm install
npm run dev
```

## Generar build
```bash
npm run build
npm run start
```

## Notas
- La app muestra pestañas por conexion y un panel de terminal simulado.
- Puedes integrar la logica real con un backend Java en el futuro.
